
## 路由

| 路徑 | 說明 |
|------|------|
| `/` | 編輯器 |
| `/explore` | 效果瀏覽 |
| `/explore?tab=animated` | 動態效果分區 |
| `/?effect=msx_ascii` | 深連結開編輯器並切 ANIMATED tab |
