## 背景

- 專案為 [Effect.app](https://effect.app/) 的 clone，逐步調整成自有產品（內部名稱 **FXCanvas**）
- Effect.app 採 **Freemium + 訂閱**（Free / Pro $12 月 / Animate $20 月）
- 共識：**$12/月對「稍微用一下」的用戶太貴**，希望造福偶爾使用的創作者
- 產品敘事：**「平時免費玩，要交稿時再付」**（Play for free, pay when it ships）
- 目標：先有一小筆收入，再慢慢優化；金流與完整商業基建可之後再加

---

## 成本結構（重要前提）

| 項目 | 誰負擔 | 隨用量暴增？ |
|------|--------|--------------|
| WebGL 渲染、匯出 | 使用者瀏覽器 / GPU | ❌ |
| 圖片處理 | 本地，不經 server | ❌ |
| 網站託管（Vercel）+ 帶寬 | 開發者 | ⚠️ 緩慢 |
| 金流手續費 | 每筆交易扣除 | 有收入才發生 |

**結論：** 邊際成本低，適合 generous Free tier + 小額付費；不必照搬 Effect.app 訂閱制。即使很多人用，server 費用也不會像 AI 生圖那樣線性暴增。

## 商業可行性評估（2026-05-29）

**結論：邏輯可行**，適合 indie 小工具、先有一筆穩定小收入；不是高轉換 SaaS 印鈔機。

### 為什麼可行

1. 單位經濟學站得住（無 per-export server 成本）
2. 定價與「偶爾用一下」用戶行為匹配
3. 組合包解決 NT$20 單筆手續費問題
4. Free 無浮水印 + 限 1080p：口碑好，4K 仍是明確付費理由

### 主要風險

1. **轉換率可能偏低** — 很多人 3 張 1080p 就夠，不再付費
2. **流量是最大變數** — 收入 roughly 隨訪客線性，需 SEO / 社群 / 示範
3. **Effect.app 競爭** — 需靠「免訂閱、對輕度用戶友善」差異化
4. **localStorage 可繞過** — 初期可接受，重度/4K 用戶仍會付
5. **商用授權未定** — 長期 B 端收入需另規劃

### 粗估範例（感覺用）

| 項目 | 數字 |
|------|------|
| 月訪客 | 3,000 |
| 實際匯出 | 600 人 |
| 買 5 張包 × 15 人 | NT$735 |
| 買 10 張包 × 5 人 | NT$445 |
| 月 gross | ~NT$1,180 |
| 金流 + hosting | ~NT$100–200 |
| 月 net | ~NT$900–1,000 |

### FAQ

**為什麼不用訂閱？**  
我們知道大多數人只是偶爾做一張圖。訂閱月費對這種用法不划算，所以改成「免費試幾張，要交稿再付」。

**Free 有浮水印嗎？**  
沒有。前 3 次匯出就是乾淨的成品，最高 1080p。

**4K 怎麼算？**  
購買點數包後，每次匯出（含 4K）扣 1 點。

**我的圖會上傳到伺服器嗎？**  
不會。特效與匯出都在你的瀏覽器裡完成。

**影片匯出呢？**  
還在規劃中，之後會另外公告。
